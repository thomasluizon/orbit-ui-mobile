screen  Four surfaces for something wrong or missing: the update gate, a missing page, a generic failure and a rate limit. Each states the fix and none apologises.

states  update, update soft, not found, failure, throttle. The soft update is a 412 shape, because the store check does not exist in a browser. No plan axis.

update  the gate has two independent sources. The server gate answers 426 with minVersion. Web draws a dismissible banner with a reload. Mobile draws a non dismissible full screen blocker with a store action. The store check never touches the API, and its soft update is a dismissible drawer on Sheet. A forced store update starts Play's own flow, which is not drawn here.

not found  says the page does not exist, names the likeliest cause in plain words, and offers the one destination that always exists, routed to Hoje. The shipping screen draws a satellite glyph, which the system does not hold, so this drawing uses the orbital mark.

failure  the boundary this state draws is the global error screen. It states that the request did not finish and that nothing was changed, then offers the retry. The reference code is the real x-orbit-request-id, in mono at fg-4.

throttle  the screen shows only the countdown, because the limit and the count give a person nothing to act on. The retry control is present and disabled while the countdown runs. The countdown is recomputed from the absolute retryAfterUtc, so backgrounding cannot desynchronise it.

accent  one filled action per state, the way forward. The throttle state has none.
