screen  The Android home screen widget at the sizes a launcher offers, plus the preview that the configuration picker shows. The launcher owns the surface behind the widget, so the backdrop here is a neutral stand in. The widget is drawn opaque, because it cannot know what is under it. There is no plan axis: the widget is not gated.

header  The header has two lines. Under the day label sits the subtitle, the only progress figure on the surface. The subtitle stays empty until the first sync. A bad habit is not counted in the figure, because a slip is not a completion.

no tokens  RemoteViews cannot read a CSS custom property, so each literal in this drawing is a flattened token and names the token it came from. The widget keeps the literals of Orbit and ignores the dynamic colour of the launcher. The accent and the mark are two of the few identity carriers that this surface has.

no fonts  A widget cannot load Geist or Space Grotesk, so it renders in the platform font. The numerals are not the display face, and nothing is tracked negative.

no icon font  RemoteViews cannot use the Tabler webfont, so each status mark is a shape that a vector drawable can hold: a filled disc with a check, a triangle and an open ring.

strings  The empty line is ONE string, shown whenever the list is empty, whether nothing was scheduled or everything is done. The signed out words are Open Orbit to sign in, in the subtitle and in the body line, with the streak hidden. Both locales are written out in full. Portuguese is the longer one and sets the truncation on the narrow sizes.

sizes  There are four sizes: 4 by 1, 4 by 2, 4 by 3 and 2 by 2. The row count comes from the geometry: the header takes 48, each row takes 48, and the remainder line takes 24. Where habits do not fit, one row gives up its place so that the line can state the remainder. The 2 by 2 drops the times. The row vocabulary never changes between sizes.

overdue  The widget computes overdue with its own rule, capped at a maximum range. This drawing shows what the widget produces. A habit whose time passed beyond the cap renders as pending here.

streak  The streak hides at zero, because a nought would only discourage. The header keeps its other content and the space closes up.

picker  The configuration preview is the shipped 4 by 2 drawing: the same header, the same three rows, the same marks and a day that includes an overdue row. It is static, because the picker cannot render live data.

touch  Every tappable region is 48 tall, the Android minimum. Tapping anywhere on the card opens the app, and the widget never logs, because a widget has no undo and no toast. Only the refresh is its own target. The signed out card is one tap target with no control, because the widget cannot sign anyone in.

refresh  The refresh can fail, and the widget has nowhere to put an error. The failed state shows the spinner gone, the control back and the old rows staying.

accent  The streak figure is the only accent, because it is progress toward something unfinished. Completion is neutral: a done row is the fg-1 disc, as in the app. The signed out state has NO accent and no control.
