screen  Two surfaces for finding something, in one document because they are the same surface at two entry points: search, and the command palette, which is that field plus the actions and destinations. At 412 they are the same sheet reached from the same field.

states  searching, no results, one result, many results, palette resting, palette typing, palette loading, the log page, the skip page, palette no match. Hover, focus-visible and press are live. No plan axis: this screen has no gate.

match field  the API returns which field matched. Every result states it: the title, the description, a tag or a child habit. A row whose title does not contain the query would otherwise look like a mistake. The fragment is quoted beside the field name only where the API returns one, the tag name or the child habit title. A title or description hit quotes nothing, so the line keeps one shape on all four rows.

results  one vocabulary for every result: the emoji well, the habit name, then the match line in mono. A child habit match names the parent. Rows lead to the habit detail, the only place a habit can be acted on.

searching  the field keeps what was typed and the list holds its own shape, so nothing jumps when the results land. It is three dots on a row and not a spinner over the screen, because the field must stay usable while the query runs.

no results  states the query back, says nothing matched, and offers one action: create a habit with that name. It parks no mark and no illustration, because this is a transient state inside a field and not a destination.

palette  at the wide width it is a centred overlay opened from the sidebar control or Ctrl K. At 412 there is no keyboard shortcut, so it is the same list reached from the search field. Four groups in the app's order: the habits, with a skeleton while they load; create, which is create habit alone, because a goal is made from a habit or by asking; actions, log a habit and skip a habit; and the destinations. Log a habit and skip a habit open a second page that lists the habits to act on, with a back control and the page's word in the field's chrome, and choosing a habit there acts. When nothing matches, the palette says so with its own line.

keyboard  the palette is a listbox: one item is active at a time and takes the selected tint and ring, arrows move it without moving focus out of the field, Enter chooses it, and Escape backs out of a page before it closes the palette. The foot carries keycap and word pairs.

accent  current position on the active palette item and the focused field ring. One filled action in the no results state, the create. None elsewhere.

open  whether a tag hit should filter by that tag and not open the one habit, and whether the palette should search logs and notes as well as habits.
