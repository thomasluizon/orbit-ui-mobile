02

The brand, in each accent

A draft mark, so the accent can be judged as an identity rather than as a button colour. It is an orbit in perspective with one body on the path: a tilted ellipse at 0.62 aspect, one stroke, no track and no partial sweep, which is deliberately not the ProgressRing shape, so a logo is never read as a completion percentage. Done is unbound from the accent: a completed habit is a neutral disc with a filled check, and the accent is reserved for what is next and what is interactive. That is why the accent survives a bad day instead of draining off the screen.

02

Hover and transition canon

A clickable thing with no hover state is a defect. Hover moves exactly one step and never uses transform: transform belongs to press. The transition is declared on the base rule, never inside :hover, so it eases out as well as in. That single mistake is what makes an interface feel cheap: the state arrives smoothly and then snaps away.
