# /morning

1. Run `/driver`. It starts the driver when it is stopped, lists every notification that sleep held overnight, the week used and the held decisions.
2. Run `/questions`. It answers and decides what it can, then asks the owner only what is his.
3. Run `/progress`. It reports the product: what shipped, and what is built but not merged.

Run each step to its end before the next. Do the work each step finds.
